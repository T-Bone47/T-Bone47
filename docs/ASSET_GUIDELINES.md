# Asset guidelines

- The profile hero is maintained in `assets/asish-engineering-banner.svg`.
- Use the graphite/amber palette documented in `docs/DESIGN_SYSTEM.md`.
- Keep SVGs self-contained; avoid remote fonts and external image dependencies.
- Every image needs descriptive alt text in README.
- Prefer diagrams and abstract technical visuals to stock photos.
- Check SVG rendering in GitHub light and dark themes before adding new assets.
