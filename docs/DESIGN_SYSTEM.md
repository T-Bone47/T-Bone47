## README rules
1. Keep the opening identity concise and strong.
2. Feature projects by engineering evidence and clarity, not repository count.
3. State project maturity accurately.
4. Keep metrics paired with a source and context.
5. Prefer original SVGs over stock artwork.
6. Test all links and image sources after editing.
7. Use GitHub-compatible Markdown/HTML only; no JavaScript or custom CSS in README.
8. Keep dynamic service images optional and explain that external services can fail.

## Asset rules
- SVGs must include a title and description.
- Use local repository-relative asset paths where possible.
- Use accessible alt text.
