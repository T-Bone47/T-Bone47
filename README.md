## 01 / The engineer behind the systems

I'm **Asish Oliver M**, an Integrated M.Tech Computer Science student at **VIT-AP**. My work sits at the intersection of AI/ML, real-time data systems, motorsport software, simulation and full-stack product engineering.

I like taking a complicated problem, understanding its underlying system, and building software that makes it measurable, useful and reliable. That means caring about architecture, data integrity, reproducible tests and the small implementation details—not just the demo.

**Current frontier** — real-time engineering intelligence, applied AI workflows, telemetry systems and simulation.
