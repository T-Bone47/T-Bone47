## How I Engineer

- **Measure before claiming.** Performance figures should be reproducible.
- **Validate before inference.** AI should be grounded in reliable data.
- **Make models explainable.** Assumptions and constraints should be inspectable.
- **Build for failure.** Testing, replay and validation are first-class features.
- **Optimize for decisions.** Software is useful when it helps someone act.
