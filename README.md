## / 01 — Engineering brief

I'm **Asish Oliver M**, an Integrated M.Tech Computer Science student at **VIT-AP**, interested in the engineering behind complex software products.

I build across the boundaries of **AI/ML, backend systems, real-time data, motorsport software and simulation**. My work ranges from telemetry ingestion and deterministic analysis to intelligent applications, product platforms and engineering tools.

I care about more than a polished interface: I want systems to have understandable architectures, measurable behaviour, reproducible tests and documentation that tells the truth about what works.

- **Currently exploring:** real-time intelligence, AI-assisted engineering workflows and simulation.
- **Engineering interests:** motorsport performance software, applied ML, distributed systems and developer tools.
- **Working style:** build, measure, validate, document, iterate.
